
# To-Do List App

A simple and responsive To-Do List web application built using HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Mark tasks as completed
- Edit existing tasks
- Delete tasks
- Filter tasks by All, Active, and Completed
- Task counter showing total, completed, and remaining tasks
- Tasks are saved using Local Storage
- Press Enter to add a new task
- Dark Mode with saved preference
- Responsive design for mobile devices
- Empty state message when there are no tasks

## Technologies Used

- HTML
- CSS
- JavaScript
- Local Storage

## How to Use

1. Enter a task in the input field.
2. Click the **Add** button or press **Enter**.
3. Click **Complete** to mark a task as completed.
4. Click **Edit** to modify a task.
5. Click **Delete** to remove a task.
6. Use the **All**, **Active**, and **Completed** filters to view tasks.
7. Use the Dark Mode button to switch between light and dark themes.

## Project Purpose

This project was created to practice and improve my skills in HTML, CSS, and JavaScript. It includes basic DOM manipulation, event handling, arrays, filtering, and Local Storage.
